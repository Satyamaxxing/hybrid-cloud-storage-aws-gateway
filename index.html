Project Title: Hybrid Cloud Storage Sync Using AWS Storage Gateway

This web application is a high-fidelity interactive simulator and operational dashboard modeled directly after the AWS Management Console (Storage Gateway & S3). It demonstrates local NVMe caching, asynchronous TLS 1.3 sync, S3 bucket versioning, CloudWatch metrics, and AWS AI services (Macie & Textract) for the final Capstone Project evaluation.
